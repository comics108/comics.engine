# flutter_comics

Flutter plugin for integrating the NativeMind Comics Engine into Flutter apps.

## Getting Started

- Add to your project:

```yaml
dependencies:
  flutter_comics: ^0.0.1
```

- Import:

```dart
import 'package:flutter_comics/flutter_comics.dart';
```
